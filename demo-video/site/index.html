What's next

    
A working prototype.
Here's where it goes.

    
Distinct voicesA Cartesia voice for every agent, so you know who's talking without looking.

    
Smarter phone callsMore languages, including Hindi and Hinglish, and interrupt the agent mid-call.

    
Safer by designSandboxed laptop tasks, an undo log for file changes, per-folder permissions.

    
More reachBeyond macOS, and approvals by WhatsApp or SMS when a call isn't convenient.

    
Cost and speedCheaper, faster models for simple agents. The strongest model stays with the Lead.

    
ProofReplay a finished run from a saved log, so a team can audit what the agents did.
