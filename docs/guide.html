Setup guide

From a fresh clone to your first run. The desk flow needs about ten minutes. Away mode (the phone call) adds a Bolna agent and ngrok.

1. Prerequisites

  • macOS (voice uses say and sox)
  • Node.js 20 or newer, and VS Code 1.95 or newer
  • sox for the microphone: brew install sox
  • Agent login: either a Claude Code login on this machine, or an ANTHROPIC_API_KEY
  • A Deepgram key for push to talk. Without it you type your answers.
  • Optional: a Cartesia key for distinct agent voices. Without it agents use macOS voices.
  • For Away mode only: a Bolna account and ngrok, logged in

2. Install and build

git clone https://github.com/parthdagia05/standup.git
cd standup/extension
npm install
npm run build

3. Add your keys

cp .env.example .env     # .env is git-ignored

Every key is optional, and a missing one falls back to something that still works.

VariableWhat it does
ANTHROPIC_API_KEYAgents use it. Without it, they use this machine's Claude Code login.
DEEPGRAM_API_KEYPush to talk. Without it a text box opens.
CARTESIA_API_KEYAgent voices. Without it, macOS say.
BOLNA_API_KEY, BOLNA_AGENT_IDAway mode phone calls.
STANDUP_PHONEYour number with country code, like +919876543210.

4. Run it

  1. Open the repo in VS Code and press F5. Choose Run Standup on demo-app.
  2. In the new window, open the Command Palette and run Standup: Open Panel.
  3. Run Standup: Start a Feature, or press ⌘⇧Space to talk.

The first time, macOS asks to let VS Code use the microphone. Allow it.

5. Phone calls (Away mode)

  1. Create an agent in the Bolna dashboard. Language: English.
  2. Prompt. The extension sends agent_name, question, options and decision_id. Use them in double braces: 
    You are {{agent_name}}, an AI developer on the user's team. Ask exactly this
question: {{question}}. The options are: {{options}}. When the user picks
one, call submit_decision with decision_id {{decision_id}} and the option
they chose. Then confirm briefly and end the call.
  3. Custom function named submit_decision, method POST, URL https://<your-ngrok-domain>/decision, with string parameters decision_id and choice. The names must match exactly.
  4. Expose the server the extension runs on port 7777: 
    ngrok http 7777 --url=<your-ngrok-domain>
curl https://<your-ngrok-domain>/health
  5. Put the agent id and API key in extension/.env.
On Bolna's trial plan you can only call verified numbers. Verify your own phone number in the dashboard first.

6. Settings

Open Settings (⌘,) and search for Standup, or edit settings.json:

{
  "standup.access": "laptop",
  "standup.phoneNumber": "+919876543210"
}
  • standup.access: project keeps agents in the repo. laptop lets them do any task on the machine.
  • standup.model and standup.leadModel: the models agents use.

Settings from an extension only appear in the window where the extension is loaded, so change them in the window you opened with F5.

7. Your first task

At the desk. Open the panel, press ⌘⇧Space, and say "Add pagination and search to todos". Watch the team form and talk. When a decision comes, answer by voice, click or type.

Away. Click Away in the panel (the status bar reads Standup: Away), start a task and step away. When a decision comes up, your phone rings and you answer by talking.

To put the demo app back to its start between runs, run demo-app/scripts/reset.sh.

Troubleshooting

The microphone doesn't work

Run brew install sox and restart VS Code completely. Allow VS Code in System Settings, Privacy and Security, Microphone.

Push to talk opens a text box

DEEPGRAM_API_KEY isn't set. Add it to extension/.env and restart the F5 window.

No voice from the agents

Check that standup.voice isn't off and your volume is up. Without a Cartesia key the agents use macOS voices.

The phone call never arrives

Open View, Output, Standup and look at the phone lines. Usual causes: a missing Bolna key, agent id or phone number, a number that isn't verified on the trial plan, or you're still in Desk mode.

The call happens but the agent doesn't continue

The function didn't reach the server. Confirm ngrok is running, the function URL ends in /decision, and the /health check works. The extension also reads the finished call as a fallback.

Agents fail to start

Run claude once and log in, or set ANTHROPIC_API_KEY in extension/.env.
